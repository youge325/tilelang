# 编程指南概览

本节提供使用 Tile Language（tile-lang）编写高性能内核的实用指南。
它参考了类似项目中的指南结构，并将其适配到 tile-lang 的概念和 API。

- 受众：使用 tile-lang 实现自定义 GPU/CPU 内核的开发者
- 前提条件：基本的 Python、NumPy/张量概念，以及对 GPU 编程概念的了解
- 范围：语言基础、控制流、指令、自动调优和类型系统

## 您将学到什么
- 如何使用 TileLang 的核心 DSL 构造来组织内核
- 如何在全局/共享/fragment 之间移动数据并流水线化计算
- 如何对 tile 大小和调度应用自动调优
- 如何在内核中指定和使用数据类型

## 建议的阅读顺序
1. 语言基础
2. 控制流
3. 指令
4. 自动调优
5. 类型系统
